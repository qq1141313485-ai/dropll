## 安装与系统

- [ ] 从 TestFlight 全新安装后能够正常启动。
- [ ] 启动页清晰，无白屏、旧 Logo 或界面闪现。
- [ ] App 名称和图标显示正确。
- [ ] 锁屏、解锁、切到后台再回来不会崩溃。
- [ ] 强制退出后重新打开，本机收藏和保存方案仍在。
- [ ] 设备旋转时保持竖屏，界面没有异常位移。

## 网络状态

- [ ] 正常 Wi-Fi 下首页和计划页可以打开。
- [ ] 蜂窝网络下可以打开。
- [ ] 断网时显示明确失败状态，不显示演示数据。
- [ ] 弱网和请求超时后可以重试。
- [ ] 网络恢复后下拉刷新可以恢复内容。

## 比分与详情

- [ ] 未赛、进行中、中场和完场排序正确。
- [ ] 进行中比分会自动更新，不长期卡住。
- [ ] 完场比赛不残留在进行中列表。
- [ ] 完场比分、半场比分和官方赛果一致。
- [ ] 比赛详情首次进入不闪现模拟内容。
- [ ] 历史交锋、近期战绩、积分和赔率的空状态合理。
- [ ] 已停售或完场比赛不能进入选号。

## 选号与方案

- [ ] 比赛按编号排序。
- [ ] 胜平负、让球、比分、总进球和半全场选择正确。
- [ ] 更多玩法布局紧凑，文字和选中状态清楚。
- [ ] 倍数输入不自动保留多余的 `1`。
- [ ] 键盘可以通过完成或点击空白处收回。
- [ ] 金额、注数和预计回报会随倍数变化。
- [ ] 奖金优化增减倍数后预算同步变化。
- [ ] 生成方案与分享图中的玩法格式一致。
- [ ] 系统分享面板能够打开，分享失败时有提示。

## 保存与结算

- [ ] 保存后可以在最近 7 天列表看到方案。
- [ ] 点击保存方案可还原当时的生成方案详情。
- [ ] 进行中、未中奖和中奖状态更新正确。
- [ ] 中奖方案显示具体税前金额。
- [ ] 组合明细能区分命中和未命中。
- [ ] 删除保存方案后不会再次出现。

- [ ] 首页不会先显示刷新动画再显示内容。
- [ ] 全部计划分页到底不会报请求异常。
- [ ] 搜索、收藏和取消收藏正确。
- [ ] 今日已更新和今日暂未更新状态准确。
- [ ] 计划详情加载失败时可以重新加载。
- [ ] 图片可以缩放、切换和下载。
- [ ] 内容投诉与下架邮件入口可以打开。
