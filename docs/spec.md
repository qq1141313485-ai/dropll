# 项目总说明

## 目标

做一个清爽的体彩工具 App，重点是比赛列表、即时赔率、完场结果和后续的数据分析能力。

## 页面边界

- 首页只负责展示比赛列表和核心状态。
- 预测页只负责模型分析结果。
- 工具页只负责计算和辅助功能。
- 所有页面都尽量保持“少按钮、少打扰、少解释”的风格。

## 开发原则

- 任何一个需求先落到文档，再落到代码。
- 每次只改一个明确目标，避免顺手重构全项目。
- 代码里不要重复写一大段业务解释，解释统一放文档。
- 接口契约、数据库字段和前端展示字段尽量一一对应。

## 建议的最小上下文

以后你让我继续做事时，最少只需要发这几类信息：

- 目标页面
- 要改的字段
- 是否允许改接口
- 是否允许改数据库

## 当前核心模块

- 抓取层：定时抓比赛和赔率
- API 层：把 SQLite 数据转成前端 JSON
- App 层：Flutter 只负责展示
- 存储层：SQLite 本地数据库
