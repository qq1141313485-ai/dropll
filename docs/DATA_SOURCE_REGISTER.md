# 数据源登记与合规状态

“公开可访问”“技术上可抓取”和“已获授权可用于产品”是三件不同的事。本文只记录
当前可核实状态；没有证据的位置必须保留“待核实”，不得补写成官方或自有数据源。

| 数据类别 | App 获取路径 | 当前用途 | 权利/合规状态 | 发布要求 |
| --- | --- | --- | --- | --- |
| 赛程、比赛状态、竞彩 SP、赛果 | `https://api.cclloo.com` 公开只读 HTTPS API | 生产功能 | 上游身份、使用条款和可再分发范围待独立核实 | 发布前完成数据来源与地区合规审查 |
| 实时比分与比赛分钟 | 服务端实时监听、数据库同步和官方结果回退 | 生产功能 | 技术链路已实现；上游使用权限及长期稳定性待核实 | 完成连续稳定性验收并保存来源依据 |
| 历史交锋、近期战绩、积分和缺阵 | 比赛分析接口及缓存 | 生产功能 | 各字段真实可用性和来源权利待核实 | 缺失时隐藏；不得用演示数据补齐 |
| 计划图片 | 计划内容服务、来源水印图片 | 条件性功能 | 授权展示、缓存、下载、地域和期限均以 `CONTENT_RIGHTS_EVIDENCE.md` 为准，当前未闭环 | 未取得证据时关闭对应内容或能力 |
| 欧赔、亚赔、大小球 | 尚未接入独立生产数据源 | 未上线 | 过去的供应商试验不构成生产授权 | 接入前完成授权、覆盖率、费用和防错配验收 |

## 登记要求

每次新增或更换数据源，至少记录：供应方及接口名称、合同或条款版本、允许用途、
再分发与缓存范围、地域、期限、更新频率、故障回退、联系人/证明文件的私密保存位置。
本文不得保存 API Key、账号密码、身份证明或合同原件。
