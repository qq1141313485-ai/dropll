# iOS 上架清单

本清单用于 App Store 提交前核对。未完成的阻塞项不应通过说明文字掩盖。

## 阻塞项

- [x] 生产 API 已迁移为 HTTPS 域名，并移除 iOS 的任意 HTTP 加载例外。
- [x] 新安装包使用服务器签发的短期设备凭据；旧长期 Token 仅保留至迁移截止日，届时必须从服务器环境中移除。
- [ ] 确认隐私政策内容与服务器日志保留策略、数据供应商协议一致；在 App Store Connect 填写公开隐私政策 URL。
- [ ] 在 App Store Connect 配置可联系的 Support URL 和开发者联系信息。
- [ ] 逐地区确认赛事数据、彩票相关计算与营销文案的合规边界；不提供出票、代购、投注或资金服务。
- [ ] 连续验证实时比分、完场赛果和已保存方案结算，不允许出现错误比分、长期卡住或空白列表。

## 提交资料

- [ ] 版本号、构建号和“最新功能”说明。
- [ ] 1024 x 1024 App 图标、真实 iPhone 截图、应用描述、关键词、分类与年龄分级。
- [ ] App Privacy 问卷，内容必须与 [隐私政策](PRIVACY_POLICY.md) 一致。
- [ ] App Review Notes：说明不提供彩票销售、代购、投注或资金服务；列出数据服务依赖与测试路径。

## 真机回归

- [ ] 冷启动、后台恢复、弱网、断网和接口超时。
- [ ] 首页、赛果、详情、选号、保存方案、结算和分享。
- [ ] 隐私政策、问题反馈和外部链接。
- [ ] iPhone 常用尺寸与 iPad 显示策略。
