# 计划内容管理

计划内容使用独立数据库和图片目录，不写入赛事数据库。

## 管理入口

- 地址：`https://api.cclloo.com/admin/plans`
- 管理员密钥保存在服务器 `/opt/caimaster-api/api.env`
- 密钥不得写入 App、Git、截图或交接文档

管理页面支持：

页面默认按非技术操作流程展示：顶部先说明今天是否有失败或待确认内容，
待确认文章按计划名称合并，计划列表支持名称搜索；手动上传、运行记录和服务检查
收在折叠区域。没有异常提示时无需日常操作。

- 新建计划
- 为计划批量上传图片
- 指定批次名称和发布时间
- 下架或恢复整个计划
- 查看并处理自动同步产生的待治理计划名称
- 查看自动同步状态摘要和最近运行记录
- 查看自动同步健康检查结果
- 将失败文章加入下一轮自动同步重试队列
- 按名称一次确认所有同名待处理文章，并在执行前显示影响数量

App 只显示服务器返回的真实计划内容。服务器无正式图片、接口失败或断网时，分别
显示明确的空状态或失败状态；不得回退到内置演示内容并将其伪装成线上数据。

## 服务器文件

- 接口模块：`/opt/caimaster-api/plans.py`
- 管理页面：`/opt/caimaster-api/plan_admin.html`
- 计划数据库：`/opt/caimaster-api/plans.db`
- 图片目录：`/opt/caimaster-api/plan-media`

图片上传后会保存原图和缩略图。首页、全部计划和更新批次使用缩略图，进入图片浏览后再加载原图。

## 公开接口

- `GET /v1/plans`
- `GET /v1/plans/recent`
- `GET /v1/plans/{plan_id}/updates`
- `GET /media/plans/{filename}`

## 下架规则

- 计划下架后，公开列表和搜索不再返回。
- 更新批次下架后，公开详情不再返回。
- 文件不会自动删除，便于误操作后恢复。
