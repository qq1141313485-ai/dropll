## 应用描述

球镜是一款面向足球赛事资料查看与本机资料整理的实用工具。

你可以查看赛事列表、比赛状态、比分和赛果，并在比赛详情中了解对阵信息、
历史交锋、球队近期战绩、积分排名及赔率变化。数据按比赛编号和状态整理，
方便快速浏览当天赛事。

主要功能：

- 查看足球赛程、比赛状态、实时比分和完场赛果
- 浏览历史交锋、球队近况、积分排名和赔率变化
- 整理胜平负、比分、总进球和半全场等资料选项
- 计算组合数量、金额及资料测算结果
- 保存本机资料，并在比赛结束后查看对应赛果和计算结果
- 在授权证据完整且范围允许时，浏览计划图片资料并使用搜索、收藏；只有授权明确
  允许用户下载时才保留下载能力
- 将当前资料生成带有球镜标识的图片并通过系统分享

球镜不要求注册账号。收藏、选择状态和保存资料保存在你的设备本机。

重要说明：

球镜仅提供赛事数据、资料展示和本机测算，不提供交易、支付、充值、提现或
其他资金服务。比赛数据和赛果可能受上游更新时间影响，最终结果请以官方公布为准。

## App Review Notes

球镜是一款足球赛事数据展示与本机资料整理工具。

1. App 不提供彩票销售、代购、出票、投注、充值、提现、返佣或任何资金服务。
2. App 不要求用户注册或登录，不包含付费功能和应用内购买。
3. 收藏、选择状态和保存资料仅保存在设备本机，不上传用户资料。
4. 比赛、赔率和赛果通过公开只读 HTTPS API 返回。
5. 计划资料库及下载能力必须在内容授权证据完成后再写入本说明。授权未闭环时，
   删除本项并从提交版本中关闭对应内容；第一版不开放用户上传、评论或内容交易。
6. 隐私政策和支持页面无需登录即可访问。

建议审核路径：

- “比分”查看赛事列表并进入比赛详情。
- “选号”选择比赛和资料选项，进入生成资料页面。
- 保存资料后，从保存资料列表重新打开。
- “计划”查看计划列表、搜索和图片详情。
- “设置”打开数据说明、隐私政策和服务中心。

如果审核期间当天没有进行中的比赛，可以查看未赛和完场比赛；核心页面不依赖
测试账号或特殊权限。

## App Privacy 填写备忘

提交前必须根据 App 和服务器的真实行为逐项填写，不要直接照抄本节作为答案。

- App 不要求姓名、手机号、邮箱、账号或支付信息。
- 本机收藏和保存方案不上传服务器。
- 服务器为了提供网络服务、安全限流和故障排查，会处理 IP 地址、请求时间、
  请求路径和响应状态，常规日志最长保留 30 天。
- 不用于广告、跨 App 追踪、数据销售或用户画像。
- 系统分享只在用户主动操作时调用。
- 需要同时核对所有第三方 Flutter 插件的数据行为。
