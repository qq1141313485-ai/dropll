# 计划内容授权与权利证明

本文用于整理“球镜”计划图片资料库的内容权利证据。证明文件不随 App
发布，也不要提交身份证件、服务器密码、API Token 或与授权无关的个人信息。

## 当前内容范围

- 内容类型：足球计划图片及其计划名称、更新时间和来源说明。
- 展示方式：App 内浏览、收藏和用户主动下载。
- 上传标识：统一显示“由球镜助手上传”。
- 用户能力：第一版不开放用户上传、评论或付费购买。
- 下架渠道：App 服务中心及 `https://api.cclloo.com/support`。

## 必须保存的证据

1. 授权方名称及其对来源网站或内容的管理关系。
2. 明确允许“球镜”转载、缓存并在 App 内展示计划图片的文字。
3. 明确是否允许用户在 App 内下载图片。
4. 授权覆盖的网站域名、栏目或内容范围。
5. 授权开始日期、有效期及终止方式。
6. 授权沟通的完整截图或正式文件，保留时间、账号和上下文。
7. 授权方可供审核核验的联系方式。
8. 如授权终止，能够及时停止采集并下架已有内容。

## 建议目录

在项目之外建立仅自己可访问的材料目录：

```text
AppStore-Content-Rights/
  01-授权确认/
  02-沟通记录/
  03-来源与范围/
  04-下架处理记录/
  05-AppReview提交副本/
```

不要把包含个人信息的原始证明推送到公开 Git 仓库。

## App Review 说明

球镜中的计划图片由已获得转载授权的来源提供。授权范围包括服务器缓存及
App 内展示；用户仅能浏览、收藏和主动下载资料。第一版不开放用户上传、评论
或内容交易。App 提供内容投诉和下架渠道，收到有效请求后可通过管理后台停止
公开展示。

此说明必须根据最终授权文件调整；如果授权不包含下载，应在提交前关闭下载功能。
